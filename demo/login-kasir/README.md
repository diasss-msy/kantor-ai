# Login aplikasi kasir (demo statis)

Halaman `login.html` dibuat dari desain Kerja (Figma `WD0UyfaypyZZu9fcIlSCre`, frame "Login / Desktop" dan "Login / PIN salah") dan spesifikasi `kerja/login-kasir/spesifikasi-login-kasir.md` di Library.

Buka langsung di browser, tidak perlu server atau backend.

- PIN demo: `123456`.
- PIN yang bukan 6 digit angka: kotak PIN merah, pesan "PIN harus 6 digit angka."
- PIN salah: "PIN salah. Sisa N percobaan sebelum akun dikunci." (N = 2, 1). Salah ketiga: "Akun terkunci. Panggil supervisor." dan tombol nonaktif. Muat ulang halaman untuk mereset.
- Di bawah 900px panel kiri tinggal baris brand dan form memenuhi layar.
